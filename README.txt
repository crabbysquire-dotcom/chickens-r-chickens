RANCH RUNNERS
=============

This download contains the complete browser game and its audio files.

To play:
1. Extract the ZIP file.
2. Serve the extracted folder with any simple local web server.
3. Open the server address in a modern desktop browser.

Opening index.html directly may not work because the game uses browser modules,
which require the files to be served over HTTP.

Controls:
- Left / Right arrow keys: switch lanes
- Up arrow: jump
- Down arrow: duck and barrel roll
- Pause button or Escape: pause

Progress, chicken name, eggs, and owned skins are saved in your browser.
